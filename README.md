# Strength Platform

AI-powered strength training and nutrition platform.

## Planned applications

- `apps/mobile` — React Native and Expo
- `apps/web` — React and Vite
- `apps/api` — NestJS REST API
- `services/vision` — Python, FastAPI and computer vision
- `packages/shared` — shared TypeScript types and schemas
- `infra` — infrastructure and Docker configuration

## Project status

Implementation of user registration and authentication.
